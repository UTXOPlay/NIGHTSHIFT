# Responsive reverse — 15.0.0

Reverse previously discarded low-speed fractional travel and had insufficient motor torque. Heavy vehicles barely moved during the first half second. V15 accumulates reverse travel, doubles reverse motor torque, raises the reverse limit from 37.8 to 54 km/h, and shortens the reverse-to-forward braking phase. Forward drivetrain and distance calculations remain unchanged. Direction changes still brake through zero; reverse cannot use nitrous.

Hold the mapped foot brake after stopping to reverse (S / Arrow Down, Colemak R). Z remains a separate reverse input. Touch can reverse with the stick already deflected sideways. Gamepad LT retains brake-to-reverse behavior. Holding the handbrake prevents the automatic change of direction.

The new native V15 executor and browser share an exact application profile. Published V8–V14 executors and native sources are retained. An unfinished historical race continues with its original handling. Explicitly start a new event to use V15; signed career progress, purchased inactive parts, personal best provenance and original proofs carry forward without reinterpretation.

Validation: 179 Node checks; Rust unit/migration tests; 200 native/browser comparisons across 67 races and all twelve events; signed replay/restart/tampering checks; exact V14 browser continuation and explicit V15 migration. All four browser inputs moved 2.4 metres in 0.5 simulated seconds with native replay verified. A barricade fixture backs away, changes lane, then passes without damage. Resize/input mapping was checked at all six required display sizes, including the portrait rotation gate. Physical phones/controllers have not been tested.

Production uses a separately measured Bookworm executable. The first build attempt failed because an empty cargo mount hid the toolchain; the second compiled successfully but its smoke command omitted Docker stdin. The final offline profile and full 390-frame browser/native trace passed against that compiled executable. Failed attempt logs remain in the private release evidence.

This scoped fix does not complete the older paused expansion goal. Multiplayer remains future work. Myelin provides off-chain host replay, not CKB settlement.
